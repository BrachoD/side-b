# Side B 🎧

A social music review platform inspired by Letterboxd.

## 🚀 Features

- User authentication (Appwrite)
- Create, edit, delete reviews
- Like system (optimistic UI)
- Follow / unfollow users
- Personalized feed
- Explore page
- Search (albums + users)
- Profile editing

## 🛠 Tech Stack

- React
- React Query
- Appwrite
- Tailwind CSS

## ⚙️ Setup

1. Clone repo
2. Create `.env` based on `.env.example`
3. Run:

```bash
npm install
npm run dev
```
